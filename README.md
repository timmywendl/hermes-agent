# HERMES legacy engineering source archive

This is a clean, history-free archival snapshot created for authorized local retirement. Original runtime files are not modified. It is not a release, Source Ready, APPLY, admission, architecture acceptance, or operational qualification.

UTF-8 source objects live at `objects/<archived_sha256>`. Per-snapshot manifests preserve relative path, original SHA-256 and archived SHA-256. For historical Hermes commits, unchanged source files are inherited from accepted fork main `60344574963861ee5d50b980338878be4f5b73af`; changed files and absent base paths are explicitly indexed. Reconstruct an old engineering tree by starting from that base, removing the listed absent paths and writing the listed objects to their original relative paths. Apply the separate working overlays only when intentionally restoring those historical edits. Objects can contain redacted account/contact/local-path or credential placeholders. Such a redacted copy is historical engineering material, not an executable production backup.

No SQLite, Session transcript, OAuth material, raw production log, credential store, Keychain export, private Memory or original private chat is included. Local user paths and email addresses are removed. Source secret scanning is completed before publication. Git and clean-source archive identities are recorded in the retirement ledger.
